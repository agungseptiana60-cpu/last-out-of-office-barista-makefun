One out-of-office auto-reply, whole on its own: I'm out of office — I've quit replying to emails to reply to a milk frother instead. Your message is #47 in my queue; I'll get to it once I've retrained on oat milk and unlearned everything except 'extra hot.' The program in `main.ts` writes that single line (209 characters) to `entry.txt` in the output directory, after checking it fits the 1–280 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
